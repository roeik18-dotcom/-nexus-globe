# PHILOS — Explainer Storyboard

**Status:** A real artifact — not prose about a future artifact. This is the
storyboard for the live `/explainer` route (same repo, same session).
**Target runtime when animated:** 90–120 seconds. **This document + the
route are the SOURCE_SUPPORTED/PROPOSED skeleton; nothing below claims to be
locked PHILOS canon.**

## Source discipline for this document

Every shot is tagged with exactly one status:

- `SOURCE_PROVEN` — quoted/built from real, already-verified material
  (canon `PHILOS-MELTING-POT-CANON.md`, or the external corpus quotes in
  `PHILOS-CORPUS-EXTRACTION-SAMPLE.md`).
- `PRODUCT_STRUCTURE` — a real, already-built product concept (Hub/Brain/
  Dynamics/Planet/Marketplace, as they exist in this repo today), not a
  corpus claim.
- `VISUAL_REFERENCE` — narrative/visual framing supplied directly by the
  user this session, used as staging only — never asserted as PHILOS
  canonical theory.

No shot below claims a fact this repo cannot back up. Where a concept is
UNRESOLVED (Self/World/Situation, Forces 7–10, a Values model), the shot
says so on screen rather than silently filling the gap.
